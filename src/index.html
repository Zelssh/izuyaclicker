How it works

Open IzuyaClicker and leave it running. It shows “Minecraft detected” when it finds your game.

Press your key (X by default) to turn it on. The status card turns green: ENABLED.

Hold the left click in the game and it starts clicking at the speed you chose.

FAQ

Windows says it protected my PC. Is it safe?

It appears because IzuyaClicker isn’t digitally signed, which Windows shows for new programs. Click “More info” and then “Run anyway”.

How do I change the activation key?

Click the key button in the window, press the key you want and it’s saved. Press Esc to cancel.

What is the Randomizer for?

It randomizes the timing of every click. The Distribution slider controls how much it varies, and the window shows the approximate CPS range.

What does Exhaust do?

It simulates hand fatigue. While you hold the click, the CPS slowly drops by up to about 30%, then gradually recovers back to your original CPS, stays there for a few seconds and starts over. If you release the click, it recovers on its own.

What is Start delay?

It waits a short moment (100 to 500 ms) before the first click each time you start holding the button. It’s on at 120 ms by default. If you use or do “Hit Select”, turn it off.

Why does it say “Waiting for Minecraft”?

The program only works when the foreground window is Minecraft. Open the game and it changes to “Minecraft detected”.

Does IzuyaClicker work on Lunar Client, Badlion Client, Cheatbreaker, etc.?

IzuyaClicker works with any client whose game window is the standard Minecraft (LWJGL) window, such as Lunar Client, Badlion Client or Cheatbreaker on 1.8. As long as your favorite client uses it, there shouldn’t be any problem. Versions 1.13 and newer use a different window and aren’t detected yet.

Is the client detectable on servers and ScreenShare (SS)?

IzuyaClicker isn’t designed to be undetectable in any way. It’s simply a project made for fun, so using it on any server where this practice is sanctioned is entirely at your own risk.
